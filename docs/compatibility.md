# 版本与实机兼容

目标是当前最新稳定版，不固定旧版本。实际版本来源为 `inspect` 输出的 `metadata.game_version`，来自存档 `version` / `savegame_version`，不从项目 README、系统日期或模型回答推测。

当前可验证范围：Python 解析/控制闭环、函数调用、MCP stdio、模拟 Win32 传输、源码包与 wheel 安装。当前没有游戏客户端，因此没有任何已获实机兼容认证的游戏版本。不能将 `verified_game_version` 配置项或 `doctor` 的 policy-ready 输出理解为自动兼容认证。

每次游戏升级后：

1. 安装升级后的可选 Mod，观察 `error.log`；先运行只记录日志的 `event saa.1 <国家ID>`。
2. 用该版本的新非铁人单人存档运行 `inspect`，确认玩家、战役、资源、战争、科技及动作验证所需字段。字段未知时停止相应动作，不对旧字段名猜测补值。
3. 重新核对本机的 UI 宏与后置条件。中文、2560×1440 是当前目标；启用 UI Mod 或修改 UI 缩放后使用单独配置并重新校准。
4. 手动试验对应事件/宏，然后验证新存档中的具体队列或订单；日志和按键不算结果。
5. 完成本机验证后把观察到的完整版本写入本地 `verified_game_version`，并锁定 `campaign_id`。游戏再次升级后版本不匹配会拒绝实时操作。

云网络当前阻止指定 Wiki；官方最新补丁查询也需要允许官方信息域名。环境配置草稿保存不等于运行时已经联网。研究记录保留参考项目的历史版本，仅作为来源信息。

# 版本与实机兼容

目标是当前最新稳定版，不固定旧版本。实际版本来源为 `inspect` 输出的 `metadata.game_version`，来自存档 `version` / `savegame_version`，不从项目 README、系统日期或模型回答推测。

本机安装为 Cygnus v4.5.2 (9776)，不是对官方最新发行版的判断。单人非铁人隔离存档已真实通过 MCP 暂停/恢复、暂停观察、精确舰队等待/同系统环绕、三领域正常科研选择，以及实际扣费的城市区划和指定分区研究实验室建设入队。建设的殖民地 ID 与物理星球 ID 分别核对，旧的直接数值相等验证已废弃。精确 EXE SHA-256 和 Frida 17.9.4 同时锁定；其他构建禁止原生调用。建筑升级/拆除、造舰、跨系统勘察/建站/殖民等仍需各自验证。详见 [逐项直接控制](direct-control.md)。

全局机制资料包含本机 4.5.2 的飞升、传统、起源、国民理念、内阁、特质、政策等定义，知识覆盖不会赋予操作权限。官方/灰机 Wiki 当前返回挑战页或 401/403，正文尚未导入。数据包版本不匹配会拒绝查询；安装数值 Mod 后需要重建资料。

此前 Windows 原生驱动初始化、文件 ChangeTime、源码包与独立 wheel、4.2.4/4.4.6/4.5.2 真实存档读取仍保留。旧 UI 宏与全面外交尚无兼容认证。版本配置或 `doctor` 的 policy-ready 输出不能理解为自动操作兼容认证。

本机运行游戏后，实际前台窗口身份、客户区尺寸读取及 DPI 坐标检查已通过，客户区为 2560×1600。Windows 窗口截图接口返回 `SetIsBorderRequired failed: unsupported interface (0x80004002)`；已通过 Steam 的 F12 本地截图读取实际界面，并核对暂停、物理学候选项及保存菜单。项目点击路径已增加目标点的根窗口命中检查，拒绝前台仍为游戏但点击点被其他窗口遮挡的情况。具体科研与保存宏的完整闭环尚待验收，不能把窗口读取或 UI 导航成功当成动作结果。

每次游戏升级后：

1. 安装升级后的可选 Mod，观察 `error.log`；先运行只记录日志的 `event saa.1 <国家ID>`。
2. 用该版本的新非铁人单人存档运行 `inspect`，确认玩家、战役、资源、战争、科技及动作验证所需字段。字段未知时停止相应动作，不对旧字段名猜测补值。
3. 重新核对本机的 UI 宏与后置条件。中文、2560×1440 是当前目标；启用 UI Mod 或修改 UI 缩放后使用单独配置并重新校准。
4. 手动试验对应事件/宏，然后验证新存档中的具体队列或订单；日志和按键不算结果。
5. 完成本机验证后把观察到的完整版本写入本地 `verified_game_version`，并锁定 `campaign_id`。游戏再次升级后版本不匹配会拒绝实时操作。

云网络当前阻止指定 Wiki；官方最新补丁查询也需要允许官方信息域名。环境配置草稿保存不等于运行时已经联网。研究记录保留参考项目的历史版本，仅作为来源信息。
